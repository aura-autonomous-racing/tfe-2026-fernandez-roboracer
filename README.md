# Construcción de un coche autónomo a escala 1:10 para la competición Roboracer

Vehículo autónomo tipo F1TENTH construido desde cero para la competición [Roboracer](https://roboracer.ai/): integración mecánica, electrónica y software en ROS 2, con navegación reactiva y seguimiento de personas por visión.

## Hardware

- Chasis Traxxas Slash 4x4
- Controladora VESC con dirección Ackermann
- Computador embarcado ZED Box Orin
- LiDAR 2D Hokuyo
- Cámara estéreo ZED X

Software: ROS 2.

## Resultados

- Vehículo completo integrado en ROS 2: chasis, electrónica de potencia (VESC), sensores (LiDAR 2D y cámara estéreo) y computador embarcado.
- Navegación reactiva: *Reactive*, seguimiento de paredes (*Follow the Wall*) y *Follow the Gap*.
- Seguimiento de personas por visión.
